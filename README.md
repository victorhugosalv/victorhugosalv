# Victor Hugo Salviano

**Estudante de Ciência da Computação (UFPB) · Full stack, engenharia de software e IA**

Gosto de construir de ponta a ponta, do banco de dados à tela que a pessoa usa, mas começo pelo problema: quem vai usar, o que precisa ser resolvido e o que pode dar errado. Comecei pelo Python, fui para o Java na faculdade e para o TypeScript nos projetos. Acompanho os modelos de linguagem com curiosidade e senso crítico: entendo onde funcionam e onde falham antes de levar para o produto.

## Projetos

### [Docenda](https://github.com/victorhugosalv/docenda) · nov/2026 – atual

Plataforma web para criar e avaliar planos de aula de Computação com IA. Em desenvolvimento: requisitos com privacidade desde a concepção (LGPD) e arquitetura concluída em 11 decisões (ADRs).
Stack planejada: TypeScript, Node.js, React, PostgreSQL, Docker, API da Anthropic.

### Rinha do Campus IV · abr/2026 – mai/2026 · em equipe

Plataforma de torneios de e-sports do Campus IV: inscrição de equipes, pagamento pelo Mercado Pago e painel de administração.
Minha parte: o módulo de torneios da API, os eventos do webhook de pagamento com logs por requisição, as telas de torneio e o painel de administração, e os testes da administração (JUnit 5, Mockito e Cypress).
Stack: Java, Spring Boot, PostgreSQL, Next.js, Docker.
Repositórios: [api-rinha-v2](https://github.com/Los-Coitados/api-rinha-v2) · [site-rinha-v2](https://github.com/Los-Coitados/site-rinha-v2)

### BichedIn · set/2026 – atual · privado

Currículos gamificados de bichos de estimação: galeria com filtros, criação com prévia ao vivo e XP ganho com petiscos. Projeto de estudo de front-end sem framework, a partir de um design próprio no Figma.
Stack: HTML, CSS, JavaScript (módulos ES), localStorage.

### [victorhugosalviano.com](https://github.com/victorhugosalv/victorhugosalviano.com)

Este site: Next.js com exportação estática, TypeScript estrito, testes E2E com Playwright e axe, acessibilidade WCAG 2.2 AA e sem cookies nem rastreamento.
